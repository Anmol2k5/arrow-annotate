Arrow Annotate Bridge

Connects your browser to the Arrow Annotate desktop app.
Checking…
Find the token in ~/.arrow/token (or %ARROW_HOME%\token) on the machine running Arrow Annotate. The token never leaves your browser storage and is only sent to 127.0.0.1.

This extension only reads page structure on http/https pages when the desktop app asks it to — it never reads page content on its own.
