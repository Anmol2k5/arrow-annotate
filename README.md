# Arrow Annotate

Local-first spatial-context tool for coding agents.

## Prerequisites

PyAudio requires system-level PortAudio headers before `pip install` will succeed:

```
# Linux
sudo apt install portaudio19-dev

# macOS
brew install portaudio
```

Windows: no extra system dependencies.

## Setup

```bash
python -m venv .venv
.venv/Scripts/activate   # Windows
pip install -r requirements.txt
python main.py
```
